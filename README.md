# 🤖 Agentic RAG Chatbot

An AI-powered Retrieval-Augmented Generation (RAG) chatbot built with Ollama and Python.

## Features

- Document Ingestion
- Knowledge Retrieval
- Context-Aware Question Answering
- Local LLM Execution
- Agentic Workflow

## Technologies

- Python
- Ollama
- RAG
- LangChain
- Vector Search

## Project Structure

- documents/
- app.py
- ingest.py
